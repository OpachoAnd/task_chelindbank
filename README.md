# task_chelindbank
Тестовая задача для вакансии в Челиндбанк

Описание решения:
    Для запуска решения необходимо запустить файл main.py, 
находящийся в корне проекта.
    Код содержит комментарии для логики решения

    Все этапы в main.py пронумерованы
    
    Для каждого из этапов решения создан свой class со своей соответствующей функциональностью:
class DataLoader - Класс для получения данных
class AggData - Класс для агрегации данных
class MacroCategorySearch - Класс для поиска топ-5 макрокатегорий 
class FeatureEngineering - Класс для подготовки новых фичей
class Clusterization - Класс для определения числа кластеров методом Локтя и Силуэта и последующей кластеризации

    Таблицы с клиентами и присвоенными кластерами сохранены в .xlsx файлах, 
которые также формируются в корне проекта при запуске решения:
1) Таблица с расчитанными показателями по макрокатегориями output_stat_df.xlsx
2) Таблица Клиенты с кластерами clients_with_clusters_df.xlsx
3) Таблица Доля расходов кластеров в соответствующей макрокатегории share_expenses_df.xlsx

    Рисунки для метода Локтя и Силуэта содержатся в корне проекта в .png файлах,
которые также формируются в корне проекта при запуске решения:
1) метода Локтя elbow_method_graph.png
2) метод Силуэта silhouette_method_graph.png

    Для запуска решения можно установить окружение автоматически командой
